CSV Requirements
  • Only standard .csv files are supported.
  • Maximum allowed file size: 16 MB.
  • The first row must contain column headers matching the required schema.
  • Expiry Date format must strictly be YYYY-MM-DD.
  • Medicines with duplicate batch numbers will be safely skipped.

Import Tips
  • Keep one medicine item per row.
  • Do not leave mandatory fields empty.
  • Batch Numbers must be unique.
  • Quantities and prices must be valid non-negative numbers.
Execution Steps
  • CSV header and format validation.
  • Batch uniqueness check.
  • Auto-creation of new medicine records.
